## 1. 프로젝트 개요

### 1.1 목적

사용자가 자신의 프로필과 환경설정을 편집하고, 변경사항을 실시간으로 확인한 후 저장하거나 취소할 수 있는 macOS 애플리케이션 화면을 개발한다.

편집 중인 설정과 마지막으로 저장한 설정을 동시에 표시하여, 저장 작업의 결과를 사용자가 명확하게 확인할 수 있도록 한다.

### 1.2 주요 기능

- 프로필 및 환경설정 편집
- 편집 중인 설정의 실시간 미리보기
- 마지막으로 저장한 설정 표시
- 편집값과 저장값의 비교
- 변경사항 저장
- 편집 취소
- 기본 설정으로 초기화
- 입력값 유효성 검사
- 미저장 변경사항 표시

### 1.3 개발 범위

본 화면은 독립적인 학습용 기능으로 개발한다.

설정값은 애플리케이션 실행 중 메모리에서만 관리하며, 실제 사용자 계정이나 외부 저장소와 연동하지 않는다.

## 2. 화면 구성

### 2.1 전체 레이아웃

화면은 다음 네 영역으로 구성한다.

| 영역 | 주요 내용 |
|---|---|
| 헤더 | 화면 제목 및 설명 |
| 프로필 비교 | Editing Preview / Saved Profile |
| 설정 편집 | 이름, 테마, 알림, 볼륨 |
| 작업 영역 | 변경사항 표시 및 작업 버튼 |

화면 크기에 따라 각 영역이 겹치지 않도록 구성해야 한다.

공간이 부족한 경우 스크롤을 허용한다.

### 2.2 헤더

다음 정보를 표시한다.

- 제목: `Profile Studio`
- 부제: `Customize your profile and preferences`
- 프로필 또는 설정을 의미하는 아이콘

### 2.3 프로필 비교 영역

두 개의 프로필 카드를 표시한다.

#### Editing Preview

현재 편집 중인 설정을 표시한다.

사용자가 설정을 변경하면 카드의 내용이 즉시 변경되어야 한다.

#### Saved Profile

마지막으로 저장한 설정을 표시한다.

사용자가 편집하는 동안에는 변경되지 않으며, 저장에 성공했을 때만 변경된다.

#### 공통 표시 항목

두 카드는 동일한 정보를 표시해야 한다.

- 프로필 아이콘
- 사용자 이름
- 선택한 테마
- 알림 활성화 여부
- 볼륨 수치
- 볼륨 게이지

두 카드의 정보를 쉽게 비교할 수 있도록 항목 순서와 기본 레이아웃을 일치시킨다.

### 2.4 설정 편집 영역

다음 항목을 순서대로 배치한다.

1. 이름
2. 테마
3. 알림
4. 볼륨

각 항목에 레이블을 표시하며, 입력 컨트롤의 정렬과 간격을 일관되게 유지한다.

### 2.5 작업 영역

다음 요소를 표시한다.

- 현재 변경사항 상태
- `Save`
- `Cancel`
- `Reset to Defaults`

각 버튼의 목적을 시각적으로 구별할 수 있어야 한다.

## 3. 초기 설정

최초 화면 진입 시 다음 설정을 사용한다.

| 설정 항목 | 초기값 |
|---|---|
| 이름 | Alice |
| 테마 | System |
| 알림 | On |
| 볼륨 | 50 |

초기 상태에서는 Editing Preview와 Saved Profile이 동일한 정보를 표시한다.

변경사항 상태는 `All changes saved`다.

## 4. 기능 요구사항

### FR-01. 사용자 이름 편집

사용자는 텍스트 입력란에서 프로필 이름을 수정할 수 있어야 한다.

**입력 규칙**

- 문자열 입력을 허용한다.
- 이름 앞뒤의 공백과 줄바꿈은 저장 시 제거한다.
- 이름 중간의 공백은 허용한다.
- 정리한 결과가 빈 문자열이면 저장할 수 없다.

**동작 규칙**

- 입력 내용은 Editing Preview에 즉시 반영한다.
- Saved Profile은 변경하지 않는다.
- 유효하지 않은 이름으로 저장을 시도하면 저장을 거부한다.
- 입력 오류 메시지를 표시한다.
- 이름 입력란으로 키보드 포커스를 이동한다.
- 유효한 이름으로 저장하면 정리된 이름을 편집값과 저장값 모두에 반영한다.

### FR-02. 테마 선택

사용자는 다음 세 가지 테마 중 하나를 선택할 수 있어야 한다.

- System
- Light
- Dark

현재 선택한 테마는 Editing Preview에 즉시 반영한다.

저장에 성공하면 Saved Profile에도 반영한다.

이번 개발에서 테마는 사용자 설정 데이터로만 관리한다. 실제 애플리케이션 전체의 색상 모드를 변경할 필요는 없다.

### FR-03. 알림 설정

사용자는 알림 기능을 활성화하거나 비활성화할 수 있어야 한다.

- On
- Off

알림 상태는 Editing Preview에 즉시 반영한다.

알림이 Off인 경우 볼륨 조절 컨트롤을 비활성화한다.

단, 기존 볼륨 값은 변경하거나 초기화하지 않는다.

### FR-04. 볼륨 조절

볼륨은 슬라이더로 조절한다.

| 항목 | 조건 |
|---|---|
| 최솟값 | 0 |
| 최댓값 | 100 |
| 변경 단위 | 5 |
| 초기값 | 50 |
| 표시 형식 | 정수 |

현재 볼륨을 숫자로 표시한다.

Editing Preview와 Saved Profile에는 각각의 볼륨 값에 비례하는 시각적 게이지를 표시한다.

알림이 비활성화되어 있는 동안 볼륨을 조절할 수 없어야 한다.

알림을 다시 활성화하면 이전 볼륨 값으로 조절을 계속할 수 있어야 한다.

### FR-05. 실시간 미리보기

Editing Preview는 현재 편집 중인 모든 설정을 표시한다.

사용자가 입력값을 변경하면 별도의 저장 작업 없이 즉시 반영되어야 한다.

Saved Profile은 마지막 저장값만 표시해야 한다.

두 미리보기 카드에서는 설정을 직접 편집할 수 없다.

### FR-06. 변경사항 상태 표시

현재 편집 중인 설정과 마지막으로 저장한 설정의 차이에 따라 상태를 표시한다.

| 조건 | 상태 메시지 |
|---|---|
| 설정이 동일함 | All changes saved |
| 설정이 다름 | Unsaved changes |

변경사항이 존재하면 사용자에게 명확하게 표시해야 한다.

편집값을 다시 이전 저장값과 동일하게 변경하면 `All changes saved`를 표시한다.

### FR-07. Save

사용자가 `Save` 버튼을 누르면 현재 편집 중인 설정을 저장한다.

**정상 처리**

1. 이름 유효성을 확인한다.
2. 이름의 앞뒤 공백과 줄바꿈을 제거한다.
3. 모든 편집 설정을 저장값에 반영한다.
4. Editing Preview와 Saved Profile을 일치시킨다.
5. 변경사항 상태를 갱신한다.
6. 기존 입력 오류 메시지를 제거한다.

**오류 처리**

이름이 유효하지 않으면 다음과 같이 처리한다.

- 저장값 유지
- 편집값 유지
- 오류 메시지 표시
- 이름 입력란에 키보드 포커스 요청

### FR-08. Cancel

사용자가 `Cancel` 버튼을 누르면 저장되지 않은 변경사항을 취소한다.

- 마지막 저장값을 편집 화면에 복원한다.
- Editing Preview에 복원된 값을 표시한다.
- Saved Profile은 변경하지 않는다.
- 입력 오류 메시지를 제거한다.
- 변경사항 상태를 갱신한다.

### FR-09. Reset to Defaults

사용자가 `Reset to Defaults`를 누르면 편집 중인 설정을 초기 기본값으로 복원한다.

| 항목 | 복원값 |
|---|---|
| 이름 | Alice |
| 테마 | System |
| 알림 | On |
| 볼륨 | 50 |

초기화 작업만으로는 Saved Profile을 변경하지 않는다.

초기화 후 `Save`를 누르면 기본 설정이 저장된다.

초기화 후 `Cancel`을 누르면 마지막 저장값으로 복원된다.

### FR-10. 입력 오류 표시

이름 유효성 검사에 실패하면 이름 입력란 근처에 오류 메시지를 표시한다.

오류 메시지:

`Please enter a valid name.`

사용자가 이름을 수정하면 기존 오류 상태를 해제한다.

### FR-11. 편집값과 저장값 비교

Editing Preview와 Saved Profile은 항상 각각의 값을 표시한다.

| 사용자 동작 | Editing Preview | Saved Profile |
|---|---|---|
| 설정 편집 | 즉시 변경 | 유지 |
| Save 성공 | 저장된 설정 표시 | 편집값으로 변경 |
| Cancel | 마지막 저장값으로 복원 | 유지 |
| Reset | 기본 설정으로 변경 | 유지 |
| Reset 후 Save | 기본 설정 표시 | 기본 설정으로 변경 |

편집값과 저장값이 서로 다른 항목을 강조색 등으로 구별하는 기능은 선택사항이다.

## 5. 시각적 디자인 요구사항

### 5.1 디자인 방향

macOS 데스크톱 애플리케이션에 적합한 단정하고 세련된 설정 화면을 제작한다.

색상, 그라디언트, 여백, 테두리, 그림자 등을 활용하여 화면의 완성도를 높인다.

단, 장식 요소가 정보 가독성과 조작 편의성을 방해하지 않아야 한다.

### 5.2 프로필 카드

- 두 카드는 시각적으로 구별되는 영역에 배치한다.
- 둥근 모서리를 적용한다.
- 최소 하나의 카드에 그라디언트를 활용한다.
- 프로필 아이콘을 표시한다.
- 이름을 다른 정보보다 강조한다.
- 설정 정보를 읽기 쉬운 형태로 배치한다.
- 볼륨 게이지의 길이가 실제 볼륨 값과 비례해야 한다.
- 두 카드의 정보 구조는 일관되어야 한다.

### 5.3 색상

- 주요 강조색을 일관되게 사용한다.
- 배경과 텍스트의 명도 대비를 확보한다.
- 비활성화 상태와 오류 상태를 시각적으로 구별한다.
- 선택한 설정 테마와 실제 화면의 디자인 색상은 독립적으로 구성해도 된다.

구체적인 색상 팔레트는 개발자가 결정한다.

### 5.4 편집 영역

- 각 입력 항목의 레이블을 명확하게 표시한다.
- 입력 컨트롤 간 정렬과 간격을 통일한다.
- 관련된 설정끼리 시각적으로 그룹화한다.
- 볼륨 값은 슬라이더와 함께 표시한다.

### 5.5 작업 영역

- Save 버튼은 주요 작업으로 강조한다.
- Cancel과 Reset은 보조 작업으로 구분한다.
- 미저장 변경사항을 쉽게 확인할 수 있어야 한다.
- 오류 메시지가 다른 컨트롤을 가리거나 화면 배치를 방해하지 않아야 한다.

### 5.6 창 크기 대응

- 창 크기가 변경되어도 주요 UI가 겹치지 않아야 한다.
- 충분한 여백을 확보한다.
- 좁은 창에서도 필수 입력 컨트롤과 작업 버튼에 접근할 수 있어야 한다.
- 필요하면 스크롤을 사용한다.

## 6. 동작 시나리오

### SC-01. 초기 화면

**조건:** 최초 화면 진입

**기대 결과**

- Editing Preview에 Alice / System / On / 50 표시
- Saved Profile에 동일한 설정 표시
- 변경사항 상태는 All changes saved
- 모든 입력 컨트롤은 초기값을 표시

### SC-02. 설정 편집 및 저장

1. 이름을 Bob으로 변경한다.
2. 테마를 Dark로 변경한다.
3. 볼륨을 75로 변경한다.
4. 두 프로필 카드를 비교한다.
5. Save를 누른다.

**기대 결과**

저장 전에는 Editing Preview만 변경된다.

저장 후에는 Saved Profile이 새로운 설정을 표시하며 두 카드의 값이 일치한다.

변경사항 상태는 All changes saved로 변경된다.

### SC-03. 저장하지 않고 취소

**초기 조건:** Bob / Dark / On / 75가 저장된 상태

1. 이름을 Charlie로 변경한다.
2. 볼륨을 30으로 변경한다.
3. Cancel을 누른다.

**기대 결과**

Editing Preview가 Bob / Dark / On / 75로 복원된다.

Saved Profile은 변경되지 않는다.

### SC-04. 기본값 초기화

**초기 조건:** Bob / Dark / On / 75가 저장된 상태

1. Reset to Defaults를 누른다.
2. 두 프로필 카드를 비교한다.
3. Cancel을 누른다.

**기대 결과**

Reset 직후 Editing Preview는 Alice / System / On / 50을 표시한다.

Saved Profile은 Bob / Dark / On / 75를 유지한다.

Cancel 이후 두 카드는 다시 Bob / Dark / On / 75를 표시한다.

### SC-05. 잘못된 이름 저장

1. 이름에 공백만 입력한다.
2. Save를 누른다.

**기대 결과**

- 저장이 거부된다.
- 오류 메시지가 표시된다.
- 이름 입력란으로 포커스가 이동한다.
- Saved Profile은 변경되지 않는다.
- 편집 내용은 유지된다.

### SC-06. 알림 비활성화

1. 볼륨을 75로 설정한다.
2. 알림을 Off로 변경한다.
3. 볼륨 컨트롤을 조작해 본다.
4. 알림을 다시 On으로 변경한다.

**기대 결과**

알림이 꺼져 있는 동안 볼륨 컨트롤은 비활성화된다.

볼륨 값은 75로 유지된다.

알림을 다시 켜면 이전 볼륨 값으로 조절을 계속할 수 있다.

### SC-07. 변경사항 비교

**초기 조건:** 저장값과 편집값이 동일한 상태

1. 이름을 다른 값으로 변경한다.
2. Unsaved changes가 표시되는지 확인한다.
3. 이름을 원래 값으로 되돌린다.

**기대 결과**

모든 편집값이 저장값과 동일해지면 별도의 Save 작업 없이 All changes saved를 표시한다.

## 7. 완료 조건

다음 조건을 모두 만족해야 한다.

- 모든 입력 컨트롤이 정상적으로 동작한다.
- Editing Preview는 편집값을 즉시 반영한다.
- Saved Profile은 Save 이전에 변경되지 않는다.
- Save 성공 후 두 카드의 설정값이 일치한다.
- Cancel은 마지막 저장값을 복원한다.
- Reset은 기본값을 편집값에만 적용한다.
- 이름 유효성 검사가 정상적으로 작동한다.
- 오류 발생 시 이름 입력란으로 포커스가 이동한다.
- 변경사항 상태가 실제 데이터와 일치한다.
- 알림 상태에 따라 볼륨 컨트롤이 활성화·비활성화된다.
- 볼륨 값은 비활성화 전후에 유지된다.
- 화면의 시각적 요소와 레이아웃이 요구사항을 충족한다.
- macOS 환경에서 빌드 및 실행할 수 있다.
